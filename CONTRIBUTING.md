# Contributing to Awesome Web Games

Thanks for helping make this list better!

## How to suggest a game

1. Fork this repo and add your entry to the right category in `README.md`, keeping alphabetical order within the section.
2. Use the exact format: `- [Name](https://example.com) - One short, objective sentence describing the game.`
3. Open a pull request with a brief note on why the game fits.

## Acceptance criteria

- Playable **instantly in the browser**: no downloads, no installs, no mandatory sign-up.
- Actually loads and works right now (dead links will be removed).
- No gambling, adult, or malware content. No pay-to-play walls.
- One entry per game; official/canonical URL preferred.

## What doesn't belong

- Mobile-only apps, Steam-only releases, or games requiring downloads.
- Link farms, SEO spam, or entries you don't have any connection to evaluating.
